मर्यादाLimitations

  • All training and test data was written for this project (training templates, test complaints and duplicate pairs drafted during the build; the external check uses the team's own midsem seed set). No real PMC complaints were used.
    • {% if ev %}
  • Accuracy inside the template data ({{ '%.1f'|format(100 * ev.department.cv_accuracy_on_train) }}%) is {{ '%.1f'|format(100 * ev.department.cv_accuracy_on_train - 100 * ev.department.accuracy.rate) }} points higher than on the separately written test complaints and {{ '%.1f'|format(100 * ev.department.cv_accuracy_on_train - 100 * ev.external_midsem.department_accuracy_coarse.rate) }} points higher than on the team's midsem set. The figures on separately written text are the ones that mean anything, and real complaints would likely be harder still. The test complaints share an author with the templates, so even the test figure is probably optimistic.
    • {% endif %}
  • The severity rules and the test-set severity labels were written by the same author, so the severity agreement figure is in-sample. The agreement with the team's independently written midsem labels is lower.
  • Speech recognition is zero-shot Whisper with no Marathi fine-tuning. {% if ae %}Measured error rates are shown above.{% else %}Real-audio evaluation has not been run.{% endif %} The character-noise results are a simulation and are labelled as such.
  • ASR guards (length, silence, repetition, no-speech) and the "transcript uncertain" flag use hand-set heuristic thresholds. ASR confidence does not affect routing.
  • No integration with PMC CARE (it has no public API). Output is a local SQLite database and per-ward CSV files.
  • SLA hours ({% for b, v in BANDS.items() %}{{ b }} {{ v.sla_hours }} h{{ ', ' if not loop.last }}{% endfor %}) are the team's proposed values, not official PMC figures.
  • Locality-to-ward assignments come from a hand-made gazetteer, not official ward boundaries. Places not in the gazetteer, ambiguous names and place names whose spelling changes when inflected can go unresolved and are sent to a person.
  • No authentication: single user, single machine. Officer corrections are logged but no retraining is implemented.
