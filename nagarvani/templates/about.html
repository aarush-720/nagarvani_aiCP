मर्यादाLimitations

  • All training and test data was written by the team. No real PMC complaints were used.
    • {% if s %}
  • Accuracy inside the template data ({{ '%.1f'|format(100 * s.cv_template_acc) }}%) is about {{ s.template_gap_points|round|int }} points higher than on the hand-written test complaints ({{ '%.1f'|format(100 * s.dept_acc.rate) }}%), so the hand-written figure is the one that means anything, and real complaints would likely be harder still.
    • {% endif %}
  • The severity rules and the severity labels were written by the same team, so the severity agreement figure is in-sample.
  • Speech recognition is zero-shot Whisper with no Marathi fine-tuning. {% if ae %}Measured error rates are shown above.{% else %}Real-audio evaluation has not been run.{% endif %} The character-noise results are a simulation and are always labelled as one.
  • ASR guards (length, silence, repetition, no-speech) and the "transcript uncertain" flag use hand-set heuristic thresholds. ASR confidence does not affect routing.
  • No integration with PMC CARE (it has no public API). Output is a local SQLite database and per-ward CSV files.
  • SLA hours ({% for b, v in BANDS.items() %}{{ b }} {{ v.sla_hours }} h{{ ', ' if not loop.last }}{% endfor %}) are proposed values, not official PMC figures.
  • No authentication: single user, single machine. Officer corrections are logged but no retraining is implemented.
